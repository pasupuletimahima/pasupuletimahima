## 🚀 Featured Flagship Project

### [E-Commerce Customer Lifecycle & Revenue Intelligence System](https://github.com/pasupuletimahima/ecommerce-customer-revenue-intelligence)
> **An end-to-end commercial analytics platform evaluating 10,400+ transactions, 6,000 customers, and $3.51M in Gross Merchandise Value (GMV).**

* 🌐 **Live Cloud Dashboard:** [**Launch Interactive Streamlit App**](https://pasupuletimahima-ecommerce-customer-revenue-intellig-app-6zblbe.streamlit.app/) *(Hosted on Streamlit Cloud)*
* 📂 **Source Code & Documentation:** [**pasupuletimahima/ecommerce-customer-revenue-intelligence**](https://github.com/pasupuletimahima/ecommerce-customer-revenue-intelligence)
* 🏗️ **Relational Architecture:** Designed an OLAP Star Schema across 6 fact and dimension tables with composite indexes.
* 👥 **Cohort Retention Matrix:** Engineered monthly retention tracking using SQL CTEs and date math, discovering an 81.6% retention drop after Month 0.
* 🎯 **RFM Segmentation:** Programmed quintile-based scoring (`NTILE(5)`) segmenting 6,000 buyers into 6 behavioral tiers, proving top 13.8% "Champions" generate 35.7% of total GMV.
* 🚚 **Logistics Diagnostics:** Correlated fulfillment SLAs with review scores, demonstrating delivery delays cause a 1,393% spike in negative ratings (4.35 ➔ 2.04 stars).
